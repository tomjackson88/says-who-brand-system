# Says Who? — Brand System

Brand system for **Says Who?**, the podcast hosted by Brogan.

> It was no longer *"How do I get there?"*
> It became: ***"Who decided where* there *was in the first place?"***

## Contents

- [`brand-system.md`](./brand-system.md) — Full brand system: origin, voice, colors, typography, logo, spacing, iconography, art direction, motion, voice examples, and anti-patterns.

## Usage

This repo is the source of truth for the Says Who? visual and verbal identity. Upload `brand-system.md` to Claude Design (or any LLM-backed design tool) to bootstrap a brand-aware design system.

## Origin

*Getting There* was one of the fastest-growing podcasts in the UK. At the height of its success, Brogan stopped — not because she ran out of things to say, but because the question changed.

*Says Who?* is the podcast born from that pivot.
